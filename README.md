# ECHO · Vinyl

Музыкальный квиз и каталог виниловых альбомов в одном приложении.

Основной адрес: **https://schallplatten.pp.ua/**
Резервный адрес приложения: https://echo-music-quiz-danil.everesko1.chatgpt.site/

## Объединённое приложение

Полный исходный код находится в **`echo/`**: React / TypeScript / Vinext, сервер Cloudflare Worker, личные таблицы D1, 100 направлений квизов, пакетное составление подборок ИИ, профиль и игровой прогресс.

Вкладка «Винил» сохраняет функции первоначального Vinyl Hunter: альбомы и отдельные прессы, собственные таблицы, поиск Discogs, цены, статусы, заметки, фильтры, импорт и экспорт Excel, песни и перенос в свои коллекции Discogs / Spotify. Интерфейс оформлен в общем стиле ECHO.

Кнопка **«Добавить альбом»** во время игры определяет реальный альбом по записи Deezer, проверяет конкретное виниловое издание и песню в его трек-листе. Повторное добавление не создаёт дублей. До ответа название альбома не раскрывается. Недоступные или неподтверждённые данные не подменяются выдуманными изданиями.

### Сохранённые коллекции и подключения

Новые данные хранятся в личном профиле; изменения из разных вкладок защищены версиями. Старые записи переносятся через «Импортировать старую коллекцию», «Firebase → ECHO» или Excel. Перенос объединяет записи и не изменяет старую базу Firebase.

Поиск и действия в личном аккаунте Discogs используют токен или OAuth; Spotify — настроенное приложение и авторизацию. Подключения можно настроить в интерфейсе. Секреты шифруются на сервере и не входят в исходный код. Доступность и лимиты внешних сервисов определяются этими сервисами.

### Разработка

```text
cd echo
npm install
npm run dev
npm run build
```

Подробности и проверки — в `echo/README.md`. Основной домен обслуживает опубликованный Sites Worker. Для публикации используются миграции `echo/drizzle/` и конфигурация `echo/.openai/hosting.json`; локальные ключи, база и файлы сборки в Git не сохраняются.

Прежний сервер Vercel временно перенаправляет главную страницу на резервный адрес ECHO: посетители со старым DNS-кэшем тоже получают новую версию. После обновления DNS основной домен напрямую обслуживает объединённое приложение.
