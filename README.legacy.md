# Vinyl Hunter (Crate Digger) 💽

Минималистичный трекер и вишлист виниловых пластинок с интеграцией **Discogs**, автоматическим расчетом цен (минимум, медиана, максимум), режимом быстрой проверки при просмотре **YouTube**, переносом в именные коллекции Discogs, экспортом в **Excel** и поддержкой облачной базы данных **Firebase Firestore**.

Создан специально для коллекционеров и любителей винила, которые ищут пластинки на барахолках, маркетах и онлайн.

---

## ⚡ Ключевые возможности

1. **YouTube Companion (Быстрая проверка)**:
   - Верхняя поисковая строка создана для работы параллельно с просмотром роликов или стримов на YouTube.
   - При вводе названия песни или исполнителя моментально показывает:
     - Либо *«Уже есть в вишлисте / коллекции»* с указанием медианной цены и состояния.
     - Либо *«Нет в списке»* с кнопкой быстрого перехода в поиск Discogs.
2. **Умный поиск по Discogs (только винил)**:
   - Ищет исключительно релизы на виниле (`Vinyl`, `LP`, `12"`, `7"`).
   - Подгружает обложки конвертов, год издания, страну пресса и лейбл.
   - Автоматически рассчитывает **минимальную**, **медианную** (VG+/NM) и **максимальную** цены на основе статистики продаж Discogs Marketplace.
3. **Ручное добавление**:
   - Если нужного издания или самиздата нет на Discogs, его можно добавить вручную с указанием обложки, параметров и цен.
4. **Интеграция с аккаунтом Discogs**:
   - Быстрая привязка через **Personal Access Token** (создается за 10 секунд в настройках Discogs).
   - Функция **«Перенести в коллекцию Discogs»**:
     - Позволяет указать **свое произвольное имя папки/коллекции** (например, *«YouTube Wishlist»* или *«Барахолка 2026»*).
     - Создает папку в вашем аккаунте Discogs и пакетно переносит туда выбранные или все пластинки с соблюдением rate-limit (60 req/min).
     - Также поддерживает перенос в официальный **Wantlist** Discogs.
5. **Экспорт в Excel (`.xlsx`)**:
   - Одной кнопкой скачивает файл Excel с аккуратными колонками: Исполнитель, Альбом, Год, Страна, Формат, Лейбл, Мин. цена, Медиана, Макс. цена, Статус, Ссылка на Discogs, Заметки и итоговая сумма.
   - Работает полностью автономно и офлайн (локальная библиотека SheetJS).
6. **Firebase Firestore & Офлайн-режим**:
   - Реальное облачное сохранение и синхронизация в реальном времени через Firebase Cloud Firestore.
   - **Гибридное хранение**: если Firebase еще не настроен, приложение мгновенно работает на локальном хранилище браузера (LocalStorage) и делает бэкап на локальном сервере в `data/records.json`.
7. **Человечный минималистичный дизайн**:
   - Теплая аналоговая эстетика (угольно-графитовые тона, виниловый янтарь, швейцарская типографика).
   - Моноширинные табличные цифры цен (`tabular-nums`), интерактивные статусы и зум обложек по клику.

## 🚀 Быстрый запуск

Сервер работает на Node.js без необходимости компиляции или тяжелых зависимостей.

```bash
# Перейдите в папку проекта:
cd C:\Users\Danil\.gemini\antigravity\scratch\vinyl-tracker

# Запустите сервер (через agy-node или обычный node):
agy-node server.js
# или
node server.js
```

После запуска откройте браузер по адресу:
👉 **[http://localhost:3000](http://localhost:3000)**

## 🔑 Подключение аккаунта Discogs

1. Перейдите в [настройки разработчика Discogs](https://www.discogs.com/settings/developers).
2. Нажмите кнопку **«Generate new token»** (Сгенерировать новый токен).
3. Скопируйте полученный токен.
4. В приложении в правом верхнем углу нажмите кнопку **«Подключить Discogs»**, вставьте токен и нажмите **«Проверить»**.
5. Приложение подтвердит имя пользователя и откроет возможность переноса пластинок в любые папки вашей коллекции!

---

## ☁️ Настройка Firebase Firestore

Если вы хотите сохранять вишлист в облаке Firebase:
1. Создайте проект на [console.firebase.google.com](https://console.firebase.google.com/).
2. Включите **Cloud Firestore** в тестовом или стандартном режиме.
3. В настройках проекта (Project settings) добавьте веб-приложение (Web app) и скопируйте объект `firebaseConfig`.
4. В приложении нажмите кнопку **«Локально (Offline)»** в правом верхнем углу, вставьте конфигурацию и нажмите **«Сохранить и подключить»**.
5. Теперь все ваши пластинки будут автоматически синхронизироваться с базой данных Firestore!
